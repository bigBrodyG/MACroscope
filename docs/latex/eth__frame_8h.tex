read frame from file in hex 

Legge un frame da un file di testo in formato esadecimale.

Formato atteso\+:
\begin{DoxyItemize}
\item una riga = un frame
\item caratteri ammessi\+: 0-\/9, a-\/f, A-\/F, spazi
\item righe vuote o che iniziano con \textquotesingle{}\#\textquotesingle{} sono commenti e vanno ignorate
\item spazi vanno ignorati
\item possibili errori\+: lunghezza dispari, caratteri non validi, se il frame non sta in bufsize, errore
\end{DoxyItemize}

Parametri\+: 
\begin{DoxyParams}{Parameters}
{\em fp} & \+: file di input già aperto in lettura testo \\
\hline
{\em buf} & \+: buffer di destinazione per i byte del frame \\
\hline
{\em bufsize} & \+: dimensione massima del buffer\\
\hline
\end{DoxyParams}
Valore di ritorno\+:
\begin{DoxyItemize}
\item len \+: lunghezza in byte del frame letto se OK
\item 0 \+: EOF raggiunto prima di leggere un frame valido
\item -\/1 \+: errore di formato (es. caratteri non validi, lunghezza dispari, dati che non stanno in bufsize)
\end{DoxyItemize}

Implementazione tipica\+:
\begin{DoxyItemize}
\item usa fgets() per leggere una riga in un buffer temporaneo
