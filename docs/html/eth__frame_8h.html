parsa primi 14 byte come header Ethernet

Interpreta i primi 14 byte di raw come header Ethernet.

Parameters
buf: passo il frame completo (L2 + payload) per indirizzo. Perchè non per copia?
eth: header Ethernet + payload successivo

Ritorna len se OK, -1 se raw->len < 14 (unico controllo di integrità).

NOTA:

  • eth->payload punta al primo byte dopo l'header Ethernet.
  • tipo viene inizializzato in base a type_or_len (>=0x0600 o <=1500).
  • la distinzione LLC / SNAP vera e propria avverrà guardando i campi LLC.

estrae MAC dest/src, type/len, inizializza payload_t deduce tipo frame (Ethernet II se type_or_len >= 0x0600, altrimenti 802.3)

◆ read_frame_from_text_file()

int read_frame_from_text_file ( FILE * fp,
uint8_t * buf,
size_t bufsize )

read frame from file in hex

Legge un frame da un file di testo in formato esadecimale.

Formato atteso:

  • una riga = un frame
  • caratteri ammessi: 0-9, a-f, A-F, spazi
  • righe vuote o che iniziano con '#' sono commenti e vanno ignorate
  • spazi vanno ignorati
  • possibili errori: lunghezza dispari, caratteri non validi, se il frame non sta in bufsize, errore

Parametri:

Parameters
fp: file di input già aperto in lettura testo
buf: buffer di destinazione per i byte del frame
bufsize: dimensione massima del buffer

Valore di ritorno:

  • len : lunghezza in byte del frame letto se OK
  • 0 : EOF raggiunto prima di leggere un frame valido
  • -1 : errore di formato (es. caratteri non validi, lunghezza dispari, dati che non stanno in bufsize)

Implementazione tipica:

  • usa fgets() per leggere una riga in un buffer temporaneo
  • skippa righe vuote / commenti
  • rimuove gli spazi dalla riga
  • chiama hex_to_bytes() per ottenere i byte nel buffer
Parameters
fpfile opened
bufbuffer di dest per i byte del frame
bufsizedimensione massima del buffer
Returns
int lunghezza del frame letto se ok, 0 se EOF, -1 se errore di formato
